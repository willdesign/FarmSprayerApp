# FarmSprayTracker
A SwiftUI app for tracking farm spraying sessions with real-time weather updates.

## Installation
1. Clone the repo: `git clone https://github.com/willdesign/FarmSprayerApp`
2. Open the project in Xcode.
3. Build and run on an iOS device or simulator (iOS 16+ required).

## Usage
- **Settings**: Enter the spray width to customize tracking accuracy.  
- **Start Session**: Tap 'Start' to begin tracking your spraying path in real-time.  
- **History**: View past sessions, including maps and weather data, in the history tab.

## Features
- Real-time weather updates during spraying sessions.  
- Customizable spray width for accurate tracking.  
- Session history with maps and statistics.

## Requirements
- iOS 16.0 or later  
- Xcode 14.0 or later
